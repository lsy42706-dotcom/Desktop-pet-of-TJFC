# 鬊鸟桌宠（Windows）

使用 WPF 开发的 Windows 桌面宠物。它会在桌面上显示，切换到其他软件时约 0.3 秒内隐藏，回到桌面后自动出现。无法读取前台窗口时，程序会保持当前显示状态，避免误隐藏。

## 从源码构建

需要 Windows 和 .NET 10 SDK。项目不依赖第三方 NuGet 包。在工程目录运行：

```powershell
dotnet publish DuckDesktopPet.csproj -c Release -o dist --self-contained false
```

构建后双击 `dist\DuckDesktopPet.exe` 运行，`duck-magenta.png` 须与程序放在同一文件夹。目标电脑需安装 .NET 10 Windows Desktop Runtime。再次双击程序会唤醒当前桌面里已运行的桌宠。

## 功能

- 玩偶会轻轻呼吸、摇摆，并定时跳动或晃动。单击可让它回应；按住左键向左右拖动时会倾身踏步，向上拖动时伸展上跳，向下拖动时下蹲弹动，松开后恢复原样。拖动位置会自动保存。
- 双击玩偶会打开当前用户桌面上的 `ChatGPT.lnk` 快捷方式。这个快捷方式实际启动什么程序，由快捷方式自身决定。
- 玩偶宽度固定为最小的 140 像素，不提供调整大小选项。
- 右键可移到右下角、重新选择双击打开的程序或退出。
- 右键玩偶或系统托盘图标可勾选“开机自启”；程序会在当前 Windows 账户的“启动”文件夹创建快捷方式，再次点击可关闭。
- 即使玩偶隐藏，也可双击通知区域（系统托盘）的图标唤醒；托盘右键菜单也可显示或退出。
- 位置和大小保存在 `%LOCALAPPDATA%\DuckDesktopPet\settings.json`。
- 不会关闭其他软件。将程序移走后，开机自启快捷方式需要重新设置。

源码仓库只包含工程、图片和说明文档；`dist`、`bin`、`obj` 和本机安装版备份均不纳入版本管理。
